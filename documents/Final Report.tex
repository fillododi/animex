\section{Main Tasks}

\subsection{User Scenario}
Giorgino is visiting a zoo with his family. As he walks through the zoo, he sees many animals that he has never encountered before and would like to learn more about their behavior, diet, routines, and natural habitats. Since Giorgino is a child, the interaction must be entertaining, immediate, and easy to understand. Moreover, because a zoo can be crowded and noisy, the application must present information clearly and concisely and must provide alternatives when speech interaction is unreliable.

\subsection{Scenario Analysis}
\begin{description}
    \item[User goal:] Identify unfamiliar animals and develop an understanding of their main traits, habits, routines, and natural habitats.
    \item[Environmental constraints:] The interaction takes place outdoors while the user may be standing or walking and holding the device in one hand. Lighting conditions can vary, background noise may interfere with speech recognition, animals may move or be partially occluded, several animals may appear in the camera frame, and the user may have only a limited amount of time for each interaction.
    \item[Main modalities:] Visual graphical interface, camera-based computer vision, touch input, spoken and written questions and answers, text-to-speech output, and an immersive 3D environment for interaction with the selected animal.
\end{description}

\subsection{Simple Task: Visual Identification}
The first task allows the user to identify an animal by framing it with the device camera. Animex periodically analyzes the camera feed and, when an animal is detected, displays its species. The recognized animal becomes the active subject for the conversational and immersive tasks.

\subsubsection{Storyboard Example}
The user notices an unfamiliar animal, points the camera towards it, and waits for recognition. Once the animal is clearly visible, the system highlights it and displays a concise result, for example: \textit{``Lion.''} The interaction is intentionally short so that it can be completed while the user is moving through the zoo.

\subsubsection{Hierarchical Task Analysis}
\begin{enumerate}
    \item Start Animex.
    \item Select an animal.
    \begin{enumerate}
        \item Point the camera at the animal.
        \item If more than one animal is detected, select the intended animal through the graphical interface.
    \end{enumerate}
    \item Read or listen to the identification.
    \item Exit the task or frame a different animal.
\end{enumerate}
\noindent\textbf{Plan:} Perform the steps in order. Step 2.2 is required only when the camera frame contains more than one possible subject.

\subsubsection{Grounding and Error Recovery}
When several animals are visible at the same time, Animex does not choose a referent silently. Instead, it highlights all detected animals and asks the user to select the intended subject by touch. The chosen animal is then shown as the current referent throughout the following interactions. This grounding loop prevents later answers, quizzes, or immersive content from being associated with the wrong animal.

\subsection{Core Task: Questions and Quizzes}
After an animal has been identified, the user can explore it in greater depth through an interactive assistant. Questions can be asked by voice or entered as text, and answers are presented in concise, child-friendly language. The assistant maintains the selected animal as conversational context so that follow-up questions such as \textit{``What does it eat?''} can be interpreted correctly.

The user can also request a quiz and select its difficulty. Animex generates true/false or multiple-choice questions about the current animal and provides immediate feedback after each answer. The quiz therefore reinforces information that the user has just discovered through the recognition and conversation tasks.

\subsubsection{Storyboard Example}
A possible interaction is the following:
\begin{quote}
    \textbf{User:} ``Where do lions live?''\\
    \textbf{System:} ``Lions mainly live in African savannahs and grasslands.''\\[0.5em]
    \textbf{User:} ``What do they eat?''\\
    \textbf{System:} ``Lions are carnivores. They hunt animals such as zebras and antelopes.''\\[0.5em]
    \textbf{User:} ``Easy quiz.''\\[0.5em]
    \textbf{System:} ``Look at the lion. Can you tell the difference between male and female?''\\
    \textbf{User:} ``Males have a mane.''\\
    \textbf{System:} ``Correct. Adult male lions are usually recognizable by their mane.''
\end{quote}

\subsubsection{Hierarchical Task Analysis}
\begin{enumerate}
    \item Start Animex.
    \item Select an animal through the visual-identification task.
    \item Ask for information about the selected animal.
    \begin{enumerate}
        \item Ask a question by voice; or
        \item enter and send a text message.
    \end{enumerate}
    \item Request and complete a quiz.
    \begin{enumerate}
        \item Choose the quiz difficulty and question type.
        \item Answer orally; or
        \item submit an answer through the graphical interface or text input.
        \item Receive feedback and, when appropriate, an explanation.
    \end{enumerate}
    \item Continue asking questions, repeat the quiz, switch animal, or exit.
\end{enumerate}
\noindent\textbf{Plan:} Perform Steps 1 and 2 first. Steps 3 and 4 are optional, repeatable, and interchangeable; the user may alternate freely between conversation and quiz interactions before exiting or selecting another animal.

\subsubsection{Grounding and Error Recovery}
The zoo environment may make spoken questions difficult to understand. If speech recognition confidence is low, the system first asks the user to repeat the utterance and keeps the current animal visible so that the conversational referent is not lost. If the second attempt is still unclear, Animex proposes text input and preserves the partial interaction state. This repair strategy allows the user to continue without restarting the task.

\subsection{Advanced Task: Natural-Habitat Immersive Experience}
The advanced task places the recognized animal inside a three-dimensional representation of its natural habitat. After the user activates the immersive experience, Animex displays the animal model together with environmental elements appropriate to the species, such as vegetation and terrain. The objective is to connect factual explanations with a spatial and visual representation of the animal's ecosystem.

The user can observe the animal from different viewpoints, interact with it by offering different types of food, and ask contextual questions through voice chat. The scene and the assistant share the same selected-animal context; therefore, the system can relate the user's actions to explanations about diet, behavior, and habitat.

\subsubsection{Storyboard Example}
After identifying a lion, the user activates the immersive mode. Animex renders a lion model in a savannah environment with grass and acacia trees. The user may then ask, \textit{``What is the lion's natural habitat like?''} The system explains that lions commonly live in savannahs and grasslands while the corresponding environmental features remain visible in the scene. The user can also offer food to the animal and observe whether that choice is appropriate.

\subsubsection{Hierarchical Task Analysis}
\begin{enumerate}
    \item Start Animex.
    \item Select an animal through visual identification.
    \item Begin the immersive experience.
    \begin{enumerate}
        \item Observe and navigate the 3D habitat.
        \item Optionally feed the animal by selecting an available food item.
    \end{enumerate}
    \item Use voice chat to ask questions about the animal or the displayed habitat.
    \item Continue interacting, return to the recognition or conversation task, or conclude the experience.
\end{enumerate}
\noindent\textbf{Plan:} Perform Steps 1--3 in order. Steps 3 and 4 may then be repeated and alternated: the user can interact with the scene, ask a question, and return to the scene as many times as desired before concluding the experience.

\subsubsection{Grounding and Error Recovery}
Voice interaction in the immersive scene uses the same repair mechanism as the conversational task. When a question cannot be understood because of background noise, the system asks the user to repeat it. If recognition fails again, the user is invited to type the question. The selected animal and the active habitat remain visible during this process, maintaining a shared visual and conversational context.

\subsection{Relationship Between the Tasks}
The three tasks form a progressive interaction flow. Visual identification establishes the animal that acts as the shared referent. The conversational and quiz task builds semantic knowledge about that referent, while the immersive task provides a spatial and interactive representation of the same information. The user is not forced through a rigid sequence after recognition: they may move between the assistant and the immersive experience while Animex preserves the selected animal and the interaction context.

\section{Project Architecture}
The Animex project is split across a two-tier architecture:
\begin{itemize}
    \item \textbf{Front-end Mobile Application}: handles user input and displays graphical interface.
    \item \textbf{Back-end Server}: receives and sanitizes requests, prompts \textit{Google Cloud}'s APIs and elaborates results for the front-end.
\end{itemize}
\includegraphics[width = \textwidth]{Deployment view.jpeg}
Given the aims of the MITA course, this report will focus on the architecture of the front-end application.

\subsection{Front-end Application}
\subsubsection{Overview}
The Animex application was developed utilizing the \textit{Typescript} programming language, the \textit{Vue}, \textit{Ionic}, and \textit{Three.js} graphical frameworks, and the \textit{Capacitor} input framework. \\
The application itself can be divided into multiple layers:
\begin{itemize}
    \item \textbf{Presentation Layer}: displays information to the user.
    \item \textbf{Module Layer}: handles the behavior needed for the system's tasks.
    \item \textbf{Service Layer}: interact with the user's device to provide the information and functions requested by the modules.
\end{itemize}
\includegraphics[width = \textwidth]{Component view.jpeg}

\subsubsection{Service Layer}
The service layer is composed of three services:
\begin{itemize}
    \item \textbf{Connection Service}: connects to the back-end server, sends HTTP requests and forwards the responses to the appropriate modules.
    \item \textbf{Camera Service}: exposes the device's camera feed.
    \item \textbf{Speech Service}: connects to the user's microphone to convert their speech to text and reads out system messages through text-to-speech.
\end{itemize}

\subsubsection{Module Layer}
The module layer is formed by three modules, one for each of the system's tasks:
\begin{itemize}
    \item \textbf{Recognition Manager}: periodically samples the camera feed through the \textit{Camera Service} and then sends the image to the back-end using the \textit{Connection Service}.
    Once the server's response is received, it saves the recognized animal as the current conversation subject or, if multiple animals were detected, it prompts the user to select one.
    \item \textbf{Conversation Manager}: keeps track of the messages sent between the user and the system's LLM, utilizes the \textit{Speech Service} to elaborate user input and system output, and provides quiz functionality.
    \item \textbf{VR Scene Manager}: renders the VR environment with the selected animal's model and background environment and handles the VR-entities and their behaviors.
\end{itemize}

\subsubsection{Presentation Layer}
The presentation layer is split across four views:
\begin{itemize}
    \item \textbf{Main Layout}: is overlaid on top of the other views, handles navigation between pages.
    \item \textbf{Recognition Page}: shows the device's camera feed, highlights identified animals in frame and allows the user to ask questions and respond to quizzes via speech.
    \item \textbf{Chat Bot Page}: shows the message history regarding the currently selected animal, allows the user to ask questions and request quizzes both via speech and via text.
    \item \textbf{Virtual Reality Page}: shows the VR scene, allows users to interact with the 3D model by giving it food and to ask questions via speech.
\end{itemize}
